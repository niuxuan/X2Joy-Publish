## 📤 如何提交模型 / How to Contribute

1. 导出 STL / 3MF（建议同时提供打印参数）
2. 放入对应子目录，更新上方清单
3. 提交 Pull Request

> 大文件（>50 MB）建议上传到 GitHub Releases 而非仓库目录。
> Large files (>50 MB): upload to GitHub Releases instead of the repo tree.
