## 🖨️ 打印说明

- 文件格式：STL
- 打印前请在切片软件中检查模型尺寸、摆放方向和支撑位置
- 层高、填充率和材料按模型结构与实际打印设备调整

## 📤 提交模型

1. 导出 STL / 3MF（建议同时提供打印参数）
2. 放入对应子目录，并在上方模型列表补充条目
3. 提交 Pull Request

> 大文件（>50 MB）建议上传到 GitHub Releases，而不是仓库目录。
